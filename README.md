# ConCalc

«Консольный» текстовый калькулятор в браузере: одно поле ввода, каждая строка вычисляется по мере набора, результат дописывается в ту же строку после маркера ` → `. Текст сохраняется между запусками, приложение ставится как PWA и работает офлайн.

Опубликованная версия: <https://doigu.github.io/ConCalc/>

## Локальный запуск

Проект собирать не нужно — это статические файлы. Но открывать по `file://` не стоит: service worker работает только по HTTP, поэтому нужен локальный сервер.

```shell
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000/>.

## Тесты

Разбор строки (`parser.js`) покрыт тестами в `tests.html` — это самодостаточный раннер без зависимостей. Открыть <http://localhost:8000/tests.html> и посмотреть результат на странице.

## Возможности вычислений

Вычисления выполняет [mathjs](https://mathjs.org/docs/expressions/syntax.html) — единицы измерения, матрицы, произвольная точность и остальной синтаксис описаны в его документации.
